## Generation workflow

The images were produced with OpenAI's built-in image-generation workflow in August 2026. No course image was supplied as a reference or edit target.

```text
Style/medium: premium natural-light editorial travel photography, realistic textures, believable geography
Composition/framing: cinematic wide landscape, strong central coastline, generous uncluttered upper area suitable for overlaid webpage copy

Constraints: entirely original scene; no text; no logos; no watermark; no visible brand; no recognizable landmark; no people
```
